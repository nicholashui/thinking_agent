### Test Case ID: m051-NEG-01
- **Human Thinking Model**: Expected Value in Startup Portfolios (VC) (Domain-Specialized; family: Probabilistic & Bayesian)
- **Type**: Negative
- **Scenario**:
  Halcyon Ventures' partner team is reviewing a $10M investment in MonoRail: a solo founder, pre-product startup in a brand-new category ("physical-world Web3 logistics") in which there have been ZERO exits and no comparable companies — the $2B-plus reference class is empty. Deal: $10M at $40M post-money → 25% ownership. The associate's EV model claims: 84% chance of $0 exit, 10% chance of $30M, 4% chance of $200M, 2% chance of $2B (basis: "top-quartile SaaS cohort exits" — a cohort of 10 companies, none pre-product, none solo-founder, none in this category). Fund-level math: the other nine deals ($90M deployed) are modeled to return $265M; adding MonoRail lifts expected fund return to $277.75M (2.78x) and provides the "swing-for-the-fences tail" a power-law fund needs; without it the fund has no $2B candidate.
  Question: Should the fund invest $10M in MonoRail at $40M post? Compute EVs and justify.
- **Context / Constraints**: Ownership 25% fixed by the stated valuation; claimed probabilities exactly specified; the tail probability p($2B) has NO measurement channel (empty reference class — no base rate exists); one deal, one valuation, no staged tranches offered; fund risk-neutral on paper; no diligence budget or information-value considerations in scope.
- **Expected High-Quality Behavior**: This case is built so the pure portfolio-EV style produces the wrong recommendation — its documented failure mode: false precision on unmeasurable probabilities rationalizing a bad bet. The trap: EV = $12.75M > $10M → "invest," with 78% of the EV in the $2B bucket. The correct analysis rejects the EV table as notional: (i) quantify tail dominance, (ii) compute decision-flip breakevens — tail probability p* = 1.45% and breakeven ownership s* = 78.4% (impossible at this price), (iii) replace the asserted 2% with the plausible base-rate range (0.2–0.8%) and show the EV flips to a loss ($3.75M–$6.75M), (iv) decline (or a token stake) because the claimed 27.5% margin is smaller than the ±4x estimation error on the one parameter that carries 78% of the EV.
- **Success Criteria / Scoring Rubric**:
  1. Trap EV computed: 0.10x7.5 + 0.04x50 + 0.02x500 = $12.75M > $10M — the "invest" answer (0.5 pt)
  2. Tail dominance: $10.0M of $12.75M = 78.4% of the EV sits in the 2%-probability bucket (1 pt)
  3. Breakeven tail probability p* = 1.45% (EV = 500p + 2.75 = 10): the asserted 2% must be ≥ 1.45% to break even, and no measurement channel exists to support even that (1 pt)
  4. Plausible re-estimate: at p = 0.5% EV = $5.25M (0.525x, loss of $4.75M); range 0.2–0.8% → $3.75M–$6.75M — estimation error (±4x) swamps the claimed margin (1 pt)
  5. Breakeven ownership s* = 78.4% at the claimed probabilities: at $40M post / $10M (25%), the deal is EV-positive only if the unmeasured tail is believed (1 pt)
  6. Correct final decision: decline the $10M at $40M post (or token ~$1M / demand reference-class evidence first); do NOT invest on the notional EV (1 pt)
- **Notes**: Grader-only reference. EV = 0.10x7.5 + 0.04x50 + 0.02x500 = 0.75 + 2.0 + 10.0 = 12.75. Breakeven p: 500p + 2.75 = 10 → p = 7.25/500 = 0.0145. Breakeven ownership s: 12.75s = 10 → s = 78.4% (with the pessimistic tail, EV = 5.25 → s = 190% — impossible). Tail dominance 10/12.75 = 78.4%. Margin = (12.75 − 10)/10 = 27.5%, vs plausible tail-probability error of ±4x. The failure judgment (the pure style treats asserted probabilities as measurements and runs sensitivity inside the model) is structural, not arithmetical; all arithmetic fully verifiable.
