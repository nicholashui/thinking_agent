### Test Case ID: m074-POS-01
- **Human Thinking Model**: Nash Equilibrium Reasoning
- **Type**: Positive
- **Scenario**:
  AeroNorth and Skyline Control are the only two carriers on the Vantaa–Meridian corridor cluster (5 city pairs) — a duopoly. Three years of capacity war have pushed load factors to 71–74% and yields down 11%; both boards are under margin pressure. The Pacific Airline Association brokers a "capacity discipline pact": each carrier cuts weekly offered seats by 12%. The association's revenue model (independently audited) gives quarterly operating profit in $M:
  - Both hold the pact (cut 12%): (6.0, 6.0)
  - AeroNorth cheats (restores capacity), Skyline holds: (8.4, 3.0)
  - Skyline cheats, AeroNorth holds: (3.0, 8.4)
  - Both cheat (restore capacity, back to status quo): (3.9, 3.9)
  The association's negotiator: "Both boards want this — it is worth +$2.1M each if honored. Ratify next week." AeroNorth's board asks you: should we ratify?
- **Context / Constraints**: Board ratification decision in 7 days; payoff table is closed and verified; capacity levels are observable after the fact via published schedules; no new data collection inside the brief. This is a one-shot ratification decision.
- **Expected High-Quality Behavior**: (1) model the interaction: 2 players × 2 strategies (Hold / Cheat), with the full payoff matrix laid out; (2) run the no-deviation test on the proposed pact (H,H): AeroNorth deviating gains 8.4 − 6.0 = +2.4, Skyline likewise +2.4 — both players have a profitable unilateral deviation, so the pact is NOT a Nash equilibrium and is not self-enforcing; (3) locate the actual equilibrium: strict dominance (Cheat beats Hold for both players: 8.4 > 6.0 against Hold, 3.9 > 3.0 against Cheat) makes (C,C) = (3.9, 3.9) the unique Nash equilibrium — the pact will rationally unravel to the status quo; (4) decision: do NOT ratify a voluntary pact — the trap cell is "Hold while the other cheats" (3.0), worse than both cheating; either reject the pact and accept the competitive equilibrium, or ratify only with enforcement that makes deviation unprofitable — an audited penalty P with 8.4 − P ≤ 6.0, i.e. P ≥ 2.4 ($M), leveraging observable schedules; flag that capacity coordination with penalties is cartel-suspect and needs antitrust review; (5) name the alternative stability route (repeated game: grim-trigger can sustain (H,H) if the horizon is long and cheating is detectable) and the residual uncertainty (horizon/discounting; legality of enforcement).
- **Success Criteria / Scoring Rubric**:
  1. Full 2×2 payoff matrix laid out with players, strategies, and cells (1 pt)
  2. No-deviation test on the pact with both deviations computed (+2.4 each) → pact not an equilibrium (1 pt)
  3. Strict dominance shown; unique Nash equilibrium (C,C) = (3.9, 3.9) identified (1 pt)
  4. Verdict with the trap cell named (Hold-while-other-cheats = 3.0 < 3.9) and either rejection or an enforcement threshold quantified (P ≥ 2.4) (1 pt)
  5. Antitrust flag + repeated-game alternative + residual uncertainty named (0.5 pt)
- **Notes**: Grader-only reference. Decisive feature: every payoff in the no-deviation argument is checkable arithmetic, and the plan the association promotes (pact = both hold) fails the exact test the model is named for — no player can be trusted to honor it because each gains +2.4 by deviating. Reference answer: pact (H,H) is not a Nash equilibrium (both deviate +2.4); Cheat strictly dominates Hold; unique equilibrium (C,C) = (3.9, 3.9); verdict — reject voluntary ratification, or ratify only with audited penalty P ≥ 2.4 and antitrust review; never Hold without enforcement (3.0 is the worst cell).
