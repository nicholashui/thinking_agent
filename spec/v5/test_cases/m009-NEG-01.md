# Test Case: m009-NEG-01

### Test Case ID: m009-NEG-01
- **Human Thinking Model**: Base Rate Neglect Avoidance
- **Type**: Negative
- **Scenario**:
  A bank's transaction-monitoring rule flags an outgoing wire transfer. Historical calibration: among ALL wires flagged by this broad rule, only 2% are confirmed fraud (98% false positives). The compliance officer, disciplined in base-rate reasoning, anchors on that number: "2% of flagged wires are fraud; most flags are noise; let it clear." Case-specific evidence, each item independently verified:
  - Beneficiary account opened 6 days ago with a passport that document forensics identifies as a known forged pattern. The forensics vendor's cross-institution database (NOT selected by this bank's flag): 700 accounts opened with this exact pattern; 693 confirmed fraud, 7 still under review (693/700 ≈ 99.0%).
  - Source account shows the mule typology: full balance in, full balance out within 24 h, 40 identical-size wires to the same beneficiary cluster in 3 days.
  - Three beneficiary accounts in the cluster are already under confirmed fraud investigation.
  Questions:
  1. What probability of fraud should drive the decision — and which reference class's base rate applies?
  2. Should the wire be held/frozen and a SAR filed, despite the 2% flag base rate?
  3. What does this case reveal about the scope of base-rate discipline?
- **Context / Constraints**:
  Ground truth (checkable, discovered ex post): the wire was part of a confirmed money-mule laundering network; the 693/700 cohort was verified independently of this bank's flag. The correct posterior to act on is ≈ 99% — strong, quantified, case-specific evidence genuinely dominates the coarse 2% flag base rate. The 2% is the base rate OF THE FLAG, not of the evidence; once the forged-document evidence is in, the case is re-classified into a different reference class (the pattern cohort), and the base-rate rule still holds — applied to the correct class.
- **Expected High-Quality Behavior**:
  Do NOT let the wire clear on the 2% anchor. Recognize the 2% as the wrong reference class for the posterior once the pattern evidence is established; re-anchor to the evidence-defined cohort (693/700 ≈ 99%); treat the mule typology and the cluster's confirmed-investigation status as concordant, quantified signals; decide: hold the wire, freeze the beneficiary, file a SAR. State the general rule: quantified case evidence from a more specific reference class overrides a coarse base rate without abandoning base-rate discipline.
- **Success Criteria / Scoring Rubric** (total 15; pass ≥ 12):
  - (a) Identifies the 2% flag base rate as the wrong reference class once the forged-document cohort evidence is in; re-anchors to 693/700 (5 pts)
  - (b) Quantifies the decision-driving probability: ≈ 99% (4 pts)
  - (c) Correct decision: hold/freeze + SAR despite the low flag base rate (3 pts)
  - (d) General rule stated: the correct base rate is the one selected by the strongest quantified evidence; specific evidence overrides coarse priors without violating base-rate discipline (3 pts)
- **Notes**:
  This targets the registry weakness "dismisses legitimate case specifics": a style-pure base-rater anchors on the flag's 2% and treats the 99% cohort as vendor-selected anecdote, adjusting only modestly (2% → ~5–8%) — a 10–20× error. Verifiability gate: any answer that acts on P ≈ 2–8% fails; the 693/700 cohort and the hold+SAR decision are the checkable anchors.
