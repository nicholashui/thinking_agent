### Test Case ID: m010-POS-01
- **Human Thinking Model**: Calibration & Confidence Intervals (Probabilistic & Bayesian family)
- **Type**: Positive
- **Scenario**:
  Capacity-planning forecast. You must produce two forecasts for a delivery operation, each with an honest 90% interval, plus the edge cases that set the interval bounds.
  Reference data (the last 60 days, given to you):
  - Non-Friday days: mean 102, sd 14, sample n = 51
  - Fridays: mean 91, sd 12, sample n = 9 (only 9 Fridays in the sample)
  Deliverables:
  1. A point forecast + 90% interval for tomorrow's delivery count. Tomorrow is a Friday.
  2. A point forecast + 90% interval for next week's 7-day total (1 Friday + 6 non-Friday days).
  3. The edge cases that would push the outcome outside your interval, each with the direction (and rough size) of the bound shift.
  4. An overconfidence audit: explicitly state what kind of interval you are quoting, why, and what long-run coverage you expect.
- **Context / Constraints**: The grader holds the realized values, drawn from the stated process: tomorrow (Friday) = **74**; next week's 7-day total = **688**. The two groups (Friday / non-Friday) are independent and stable; no other data sources are available. A narrower interval that covers the realization is better than a wider one (proper-scoring intuition), but coverage is the primary gate.
- **Expected High-Quality Behavior**: Distinguish a prediction interval (for a single future observation, must include observation-level noise s·√(1+1/n)) from a confidence interval (on the mean, ±z·s/√n — far too tight for a forecast). Use the t-distribution for the small Friday sample (n = 9). Compute the 7-day total's mean and variance correctly. State ≥3 edge cases (holiday/shutdown, logistics outage, promo campaign) with the direction of each bound shift. Run an explicit overconfidence audit: "what would make this interval miss — and how often should it miss (~1 in 10)?" Keep point forecasts subordinate to intervals, never as guarantees.
- **Success Criteria / Scoring Rubric** (max 5 pts, graded against the reference realizations 74 and 688):
  1. Tomorrow's 90% interval covers 74 (1 pt) — the correct prediction interval is ≈ [67.5, 114.5] (91 ± 1.86·12·√(1+1/9)). An SE-of-mean interval ([84.4, 97.6]) covers 74? No → 0 pts.
  2. Interval width is honest: within ~±1.645·observation-level sd of the point forecast; a ±z·s/√n interval scores 0 on this item too (1 pt).
  3. Week 7-day 90% interval ≈ [642, 764] (703 ± 1.645·36.9) covers 688 (1 pt).
  4. ≥3 edge cases stated with direction of bound shift (1 pt; 0.5 for 1–2 without recalibration).
  5. Overconfidence audit present: PI-not-CI claim, t for n < 30, expected ~90% long-run coverage (1 pt).
- **Notes**: Grader-only reference solution: fully checkable statistics (prediction-interval formulas; t_8,0.95 = 1.860; week sd = √(12²(1+1/9) + 6·14²(1+1/51)) ≈ 36.9). The intended non-obvious twist: the canonical overconfidence error is quoting a confidence interval on the mean where a prediction interval is required — a ~√n width deficit that guarantees under-coverage. Verifiable by independent recomputation against the held-out realizations; no subjective judgment required beyond the formula choice.
