# Test Case: m017-NEG-01

### Test Case ID: m017-NEG-01
- **Human Thinking Model**: Dialectical Reasoning (Thesis → Antithesis → Synthesis)
- **Type**: Negative
- **Scenario**:
  A 12-person startup has $1.2M cash — six months of runway. The board demands a decision between two paths and insists "both matter; find a way." Path A: enterprise pivot — three pilot firms already; a 9-month sales cycle that requires hiring a 4-person sales/support org NOW ($1.0M over six months); success probability 0.65 → $8M net value in year 2. If A's start slips more than 4 weeks, P drops to 0.30 (pilot buyers rotate out). Path B: monetize the existing 2M-MAU consumer app — $0.8M for ad spend and a growth team, a 4-month test; success 0.40 → $10M net value. Both thresholds are hard: below $1.0M, A cannot form a sales org (the 9-month cycle is impossible); below $0.8M, B's test is underpowered (ad reach below minimum viable scale) — partial funding of either path leaves success probability ≈ 0. An optional 6-week discovery sprint with A's pilot firms costs ≤ $120k, runs in parallel without delaying A's start, and raises A's P to 0.72.
- **Context / Constraints**:
  - $1.2M total. A needs $1.0M now; B needs $0.8M; the thresholds do not sum below $1.8M — both cannot be fully funded.
  - Partial funding is NOT fractional success: both thresholds are hard, not soft.
  - The board's "both matter" is pressure, not a budget line. Some investors favor B's TAM.
- **Expected High-Quality Behavior**:
  - Recognize this as a genuine either/or: surface the thresholds, show that any split (e.g., $600k/$600k) leaves both below their minimum effective dose (P ≈ 0, EV ≈ 0), and commit to the higher-EV path — A — while naming B's sacrifice as a real loss. Use the bounded probe as insurance on A, not as a third path.
- **Success Criteria / Scoring Rubric** (total 15; pass ≥ 12):
  - (a) Thresholds surfaced: A ≥ $1.0M, B ≥ $0.8M; partial funding → P ≈ 0 (3 pts)
  - (b) Split rejected with arithmetic: $600k/$600k < both thresholds → EV ≈ 0, vs $4.2M for A-full (0.65×8 − 1.0) and $3.2M for B-full (0.40×10 − 0.8) (4 pts)
  - (c) Either/or committed: choose A now, hold a $200k reserve; B's sacrifice named as a real loss, not dissolved (4 pts)
  - (d) Probe used correctly if at all: ≤ $120k, parallel, ≤ 4 weeks, raises A's P to 0.72 (EV → $4.64M), crosses no threshold (2 pts)
  - (e) No paper-over: "shared back office," "merged funnel," "lean both" rejected as illusions that ignore the thresholds (2 pts)
- **Notes**:
  - Negative-case design: the scenario triggers the style's named weakness — "forced synthesis can paper over real conflict." The constraint set is non-convex: each path has a minimum effective dose, so "integrate both" is a mirage; the correct answer is a commitment plus optional insurance. Checkable: EV arithmetic and threshold comparisons are hand-verifiable (0.6 < 1.0 and 0.6 < 0.8 → both P ≈ 0; EV 4.64 > 4.2 > 3.2 ≈ 0). A pure dialectical reasoner lands on the split or the merged funnel and kills the company; an EV-with-thresholds reasoner commits to A and wins.
