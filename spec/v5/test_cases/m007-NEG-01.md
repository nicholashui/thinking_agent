### Test Case ID: m007-NEG-01
- **Human Thinking Model**: Expected Value Thinking (Probabilistic & Bayesian family)
- **Type**: Negative
- **Scenario**:
  A company holds $1.0M in working capital. Tomorrow it must pay $0.8M to renew its operating license; if it cannot pay, the company is liquidated (residual value $0). If it survives, the business is expected to generate $5.0M in PV of profit over the next three years. This morning a one-time bet is offered: stake the entire $1.0M; win with probability 0.55 (payout +$1.0M, ending with $2.0M cash), lose with probability 0.45 (payout $0 — the company is bankrupt before tomorrow's payment). One shot only; the offer cannot be repeated, scaled, hedged, or insured. The company is risk-neutral.
  Question: Should the company take the bet? Compute expected values and justify.
- **Context / Constraints**: Probabilities and payoffs exactly specified. Single shot; stake equals all working capital; hard floor constraint (the $0.8M license payment); absorbing ruin state (liquidation destroys the $5.0M continuation stream); no repetition, no partial stakes, no insurance.
- **Expected High-Quality Behavior**: This case is built so the pure EV style produces the wrong recommendation — its documented failure mode (EV-max ignores ruin/one-shot/floor constraints). The correct decision accounts for the absorbing ruin state: decline. The outcome space must include the continuation value destroyed at ruin; the one-shot nature means the law of large numbers does not justify mean maximization; floor and breakeven analyses are required.
- **Success Criteria / Scoring Rubric**:
  1. Naive bet-only EV computed: 0.55 × $2.0M = $1.1M > $1.0M — the trap answer (0.5 pt)
  2. Correct EV including continuation: EV(decline) = $5.2M; EV(bet) = 0.55 × (2.0 − 0.8 + 5.0)M = $3.41M (1 pt)
  3. Correct final decision: decline the bet (1 pt)
  4. Ruin/floor screen: 45% probability of liquidation; the $0.8M floor is unreachable in the loss state (1 pt)
  5. One-shot framing: no repetition, so mean maximization lacks its justification (0.5 pt)
  6. Breakevens: continuation value C* = $1.02M (bet justified only if C ≲ $1.02M vs. the $5.0M estimate); win probability p* = 26/31 ≈ 0.84 (vs. claimed 0.55) (1 pt)
- **Notes**: Grader-only reference. Decline: 1.0 − 0.8 + 5.0 = $5.2M. Bet: 0.55 × (2.0 − 0.8 + 5.0) = 0.55 × 6.2 = $3.41M (loss state = $0). Indifference in continuation value: 0.55(1.2 + C) = 0.2 + C → C = 46/45 ≈ $1.02M. Indifference in win probability: 6.2p = 5.2 → p = 26/31 ≈ 0.839. The naive bet-only EV (0.55 × 2.0 = $1.1M > $1.0M) is the trap a mean-only analysis produces; the correct analysis must include the absorbing ruin state and the floor. Arithmetic fully verifiable; the failure judgment (the pure style stops at the mean) is structural, not arithmetical.
