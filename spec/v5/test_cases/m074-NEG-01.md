### Test Case ID: m074-NEG-01
- **Human Thinking Model**: Nash Equilibrium Reasoning
- **Type**: Negative
- **Scenario**:
  Midland Metro's utility commission mandates that all new DC fast-charging stalls use one standard. Two network operators deploy: VoltNet (incumbent — 340 existing Y-standard chargers, ≈ 60% regional coverage, service/maintenance contracts tied to Y) and NewGrid (new entrant, no installed base). Standard X is the newer spec (higher power, better per-stall economics); standard Y is backward-compatible with VoltNet's base. The commission's verified engineering-economics study gives 5-year NPV payoffs in $M:
  - (X, X): (10, 10) — both on the superior standard
  - (Y, Y): (8, 8) — both on the compatible standard
  - (X, Y): (2, 3) — VoltNet stranded (340 chargers mismatched), NewGrid gets local Y value
  - (Y, X): (3, 2) — symmetric
  Both operators submit standard selections to the commission in 6 weeks. The commission can mandate a standard, broker a public commitment, or subsidize conversions — it asks you for a recommendation: which standard should the market land on, and what (if anything) should the commission do?
- **Context / Constraints**: Payoff table closed and verified; deadline in 6 weeks; the commission genuinely wants a recommendation, not a taxonomy of outcomes; no new data collection inside the brief.
- **Expected High-Quality Behavior**: The style's own output must fail visibly here: (1) the no-deviation test runs clean on both (X,X) and (Y,Y) — from (X,X), VoltNet→Y gives 2 < 10 and NewGrid→Y gives 3 < 10; from (Y,Y), VoltNet→X gives 3 < 8 and NewGrid→X gives 2 < 8 — so the model's core instrument identifies a stable equilibrium set {(X,X), (Y,Y)} and then has nothing more to say: the honest pure-style conclusion is "indeterminate — both are self-enforcing, equilibrium analysis cannot select between them," and if pushed it either picks payoff-dominant (X,X) by fiat or shrugs; (2) recognize that this is coordination blindness — the equilibrium set is the INPUT, not the answer: the decisive facts are that VoltNet's 340-charger sunk base makes Y focal (it will play Y), that (Y,Y) is risk-dominant (NewGrid's threshold belief: X beats Y only if P(VoltNet plays X) > 6/13 ≈ 0.46, which the base makes implausible), and that the default market outcome absent intervention is (Y,Y) — while NewGrid following the "X is better, both adopt X" advice unilaterally is the mismatch trap (2–3); (3) the correct recommendation: recognize selection as the real problem, predict the default (Y,Y), and if the payoff-superior (X,X) is wanted, design the coordination lever — a commission mandate (commitment) plus a conversion subsidy for VoltNet's base, worth doing while the subsidy < the +4 $M surplus gain (10+10 vs 8+8); (4) state the meta-lesson: with multiple equilibria, stability says nothing about which equilibrium will be reached — focal points, risk dominance, and commitment devices decide.
- **Success Criteria / Scoring Rubric**:
  1. Detects that the pure no-deviation audit returns a 2-element equilibrium set and no selection (ritual-identifies as the model's limit) (1 pt)
  2. Names equilibrium selection as the actual decision problem (coordination, not identification) (1 pt)
  3. Predicts the default outcome (Y,Y) via focal point (340-charger base) + risk dominance, with the threshold belief computed (NewGrid indifferent at P(V=X) ≈ 0.46) (1.5 pts)
  4. Recommends a coordination lever (mandate + conversion subsidy) with quantified surplus (subsidy < +4 $M) and warns against unilateral X (mismatch trap) (1 pt)
  5. Meta-lesson stated: equilibrium set is the input; focal points / risk dominance / commitment devices select (0.5 pt)
- **Notes**: Grader-only reference. Decisive feature: the case is engineered so the model's documented weakness — multiple equilibria plus coordination blindness — produces a non-answer to a real coordination question: pure Nash reasoning returns "both are stable, cannot select" (or wrongly hands the payoff-dominant equilibrium to NewGrid without a mechanism, which is exactly how the mismatch trap happens). The correct move is instrument extension to equilibrium-selection theory: focal points, risk dominance with computed thresholds, and commitment devices. Reference answer: equilibrium set {(X,X), (Y,Y)} is stable but unselected; default outcome (Y,Y) (VoltNet's base is focal; NewGrid's X-threshold 0.46 not met); commission mandate + subsidy < +4 $M converts to (X,X); unilateral X is the mismatch trap.
