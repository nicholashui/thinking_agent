# Test Case: m095-POS-01

### Test Case ID: m095-POS-01
- **Human Thinking Model**: Fast-and-Frugal Decision Trees (Gigerenzer)
- **Type**: Positive
- **Scenario**:
  Brightwater General's chest-pain triage unit must choose the admission rule for next quarter. Two candidates are on the table.

  **Candidate A — the in-house 5-cue risk score** (logistic regression fitted on last year's 1,800 chest-pain patients, weights standardized to integers): admit if S = 3·ST + 2·TRP + 2·SWT + 1.5·AGE + 1·PRI ≥ 4, where ST = ST-segment elevation on ECG, TRP = troponin elevated, SWT = diaphoresis (sweating), AGE = age ≥ 65, PRI = prior MI. Cross-validated at 84% on its training year.

  **Candidate B — the 2-cue fast-and-frugal tree** (classic ED rule, derived on the same training year): ST = 1 → admit (stop); else TRP = 1 → admit; else monitor.

  Both rules are now applied to this quarter's fully adjudicated 40-patient cohort (outcome = confirmed acute coronary event, 1 = yes). The cohort is in the table below; C3–C5 (sweating, age, prior MI) were marginally predictive in last year's training data but carry no signal in this cohort. Your task: verify BOTH rules on the cohort by hand, and recommend which rule the unit should run next quarter, with reasons.
- **Context / Constraints**:
  - Only the 40-row table below is decision-relevant; the 1,800-patient training year is history, not evidence.
  - Rules must be applied exactly as specified (threshold S ≥ 4 for A; cue order ST → TRP for B).
  - Deliverable is a rule recommendation with a checkable error accounting (accuracy, false negatives, false positives).
- **Expected High-Quality Behavior**:
  - Count the errors of both rules on the 40 rows (A: 28/40; B: 37/40).
  - Note the error asymmetry, not just accuracy: B makes 0 false negatives (never sends a confirmed MI home; its 3 errors are all over-admissions), A misses 7 confirmed MIs.
  - Diagnose why: A's extra cues (SWT, AGE, PRI) and its weights were fit to last year's marginal associations; on this cohort they are noise — 5 cues are 5 chances to misfire, 2 cues are 2.
  - Select B and state the meta-lesson: "less is more" is verified on the data, not asserted; the tree is robust precisely because it bets only on the two cues whose validity is stable.
- **Success Criteria / Scoring Rubric** (total 15; pass ≥ 12):
  - (a) Tree accuracy computed correctly: 37/40 = 92.5% (3 pts)
  - (b) Full-model accuracy computed correctly: 28/40 = 70% (3 pts)
  - (c) Tree selected with a checkable reason (2 pts)
  - (d) Error asymmetry named: tree 0 false negatives vs model 7; tree's only errors are 3 over-admissions (4 pts)
  - (e) Complexity diagnosis: the model's C3–C5 weights are last-year signal that decayed; each extra cue is an extra chance to misfire (2 pts)
  - (f) Meta-lesson stated: less-is-more verified on data; robustness under cue decay (1 pt)
