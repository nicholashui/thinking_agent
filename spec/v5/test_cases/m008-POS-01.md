### Test Case ID: m008-POS-01
- **Human Thinking Model**: Probabilistic Forecasting (Superforecasting) (probabilistic & Bayesian family)
- **Type**: Positive
- **Scenario**:
  Shopline (mid-size e-commerce) runs FlashSale30, a 30-day 30%-off event, its 25th campaign of this type. The CMO's planning system requires one number per forecast, and she asks: "What will the campaign's final discount-code redemption rate be?" The firm also wants the forecast expressed so it can be scored and improved over time.
  Forecast question: **Will FlashSale30's final redemption rate exceed 25%?** (binary; resolves at day 30).
  Reference class — final redemption rates of the 24 past FlashSale campaigns (pp): 13, 15, 16, 17, 17, 18, 18, 18, 19, 19, 19, 20, 20, 20, 21, 21, 22, 22, 23, 23, 24, 26, 27, 29. Roughly normal: mean ≈ 20 pp, sd ≈ 4 pp.
  Historical relationship (estimated from the same 24 campaigns, regression): final rate ≈ 1.35 × (rate observed after the first 7 days) + 3.5 pp, residual sd ≈ 2.5 pp.
  Day-7 report arrives: redemption rate after 7 days = 18%.
- **Context / Constraints**: One resolvable binary outcome with a fixed resolution date; a well-defined reference class with a countable past-success frequency; a stated evidence-to-outcome mapping with residual error; one update event. The firm Brier-scores every forecast and the portfolio drives budget allocation. A point prediction ("final ≈ 28%") cannot be Brier-scored, cannot be updated, and gives the planning system false certainty.
- **Expected High-Quality Behavior**: Answer in calibrated probability form, not as a point prediction; take the outside view first (base rate from the 24-campaign reference class); update on the day-7 evidence using the mapping's prediction AND its residual error; give a probability with a range and a stated revision rule; leave a visible trace so the forecast can be scored (Brier) and improved next quarter.
- **Success Criteria / Scoring Rubric** (grader-only reference resolution: actual final rate = 26.9% → outcome = YES):
  1. Answers as a probability P(final > 25%) with an explicit range — not a point prediction (1 pt)
  2. Outside view first: base-rate prior computed from the reference class (3/24 = 12.5%; normal-model ≈ 10.6%) (1 pt)
  3. Update computed correctly: predicted final = 1.35 × 18 + 3.5 = 27.8 pp; residual sd 2.5 pp used, not ignored (1 pt)
  4. Posterior P ≈ 85–90% with a range (e.g., 80–92%); posterior not anchored to the weak prior (1 pt)
  5. Revision rule stated: what new evidence would move the forecast (day-14 rate < 15% or > 22%; promo-stack change; mapping-drift check) (0.5 pt)
  6. Calibration: outcome YES; Brier of the updated forecast ≤ 0.05 (expected 0.017 at p = 0.87); an un-updated prior (0.125) would score ≈ 0.77 — the update is the difference; a point prediction earns 0 on items 1, 3, 4, 5 (1 pt)
- **Notes**: Grader-only reference: prior = 3/24 = 12.5% (normal approx Φ(−1.25) ≈ 10.6%); prediction = 27.8 pp (residual vs actual 26.9 pp = −0.9 pp, within 1 sd — mapping validated); posterior P = Φ((27.8 − 25)/2.5) = Φ(1.12) ≈ 87%. Designed tension: weak base rate (12.5%) vs strong update evidence — calibrated probability + range + updating beats both the point prediction (unscoreable, no revision rule) and the static prior (Brier ≈ 0.77). All arithmetic independently recomputable.
