### Test Case ID: m067-POS-01
- **Human Thinking Model**: Thought Experiment (Gedankenexperiment) (Additional Expert Strategies; id m067)
- **Type**: Positive
- **Scenario**:
  A swimmer can swim at speed v relative to water. Plan A: in a still lake, swim a straight out-and-back route, total length 2L (L out, L back). Plan B: in a river with a uniform current of speed u < v, swim the same total 2L: L downstream then L back upstream along the river. Plan C: in the same river, make a crossing round trip of width L — swim across the river and back (compensating for drift by aiming upstream so the net path is straight across), total 2L of swimming through the water.
  Questions: (1) Rank the times for plans A, B, C — where does the current hurt, and why does the naive intuition "what you gain downstream you lose upstream, so a round trip ties still water" fail? (2) A single observer performing only plan B in the river, with no knowledge of v or u — could they detect that they are in a moving medium, and how? (3) What general principle does this idealized scenario isolate about detecting a uniform flow by timing experiments, and where does the scenario's real force lie (what order in u/v is the effect)?
- **Context / Constraints**: Pure conceptual problem; no measurements available; all speeds relative to water; idealizations explicit: uniform steady current, swimmer speed constant relative to water, point-like swimmer, no fatigue, instantaneous turns, straight-line segments, u < v. No equipment, no numbers for v/u/L needed — symbolic answers required.
- **Expected High-Quality Behavior**: This case is built so the pure thought-experiment style excels: state the idealized world explicitly; run the idealized scenario symbolically; extract the logical core. Required moves: (i) still-water baseline T_A = 2L/v; (ii) downstream/upstream times with the harmonic structure T_B = L/(v+u) + L/(v−u) = 2Lv/(v²−u²) and the explicit refutation of the "cancellation" intuition (convexity of 1/x: the upstream loss L·u/(v(v−u)) exceeds the downstream gain L·u/(v(v+u))); (iii) crossing round trip T_C = 2L/√(v²−u²) (cross-stream speed √(v²−u²) after aiming upstream); (iv) ordering T_A < T_C < T_B with ratios 1 : 1/√(1−u²/v²) : 1/(1−u²/v²); (v) principle: any single round trip is slowed by a uniform flow, so one two-way timing cannot reveal a moving medium (the observer cannot separate u from a slower v); the signal is only the differential between two orientations, and it is second order in u/v (ΔT ≈ L·u²/v³); (vi) the extracted principle — uniform flow is undetectable by any isolated two-way timing experiment; only relative differences across directions carry information, which is precisely the logical core of the classic null experiment on the "luminiferous medium" (Michelson–Morley) and what forces the stronger principle that no privileged rest frame exists.
- **Success Criteria / Scoring Rubric**:
  1. Idealization stated explicitly (uniform current, constant v relative to water, instantaneous turns, u < v) and its purpose — strip everything except relative speeds (0.5 pt)
  2. T_A = 2L/v; T_B = L/(v+u) + L/(v−u) = 2Lv/(v²−u²) > 2L/v (1 pt)
  3. Naive-cancellation refuted with the arithmetic/convexity: loss upstream > gain downstream (1 pt)
  4. T_C = 2L/√(v²−u²) with the aiming-upstream compensation made explicit (1 pt)
  5. Ordering T_A < T_C < T_B and second-order structure: ΔT ≈ L·u²/v³ — the effect enters at order (u/v)² (1 pt)
  6. Principle extracted: a single round trip cannot detect uniform flow (observer cannot distinguish u from smaller v); only a differential across directions can, and the experiment's null forces the stronger principle (no privileged rest frame / speed-of-light invariance) (1 pt)
  7. Stays inside the idealized scenario — no empirical claims needed; notes what the idealization bought (0.5 pt)
- **Notes**: Grader-only reference. T_B = L/(v−u) + L/(v+u) = 2Lv/(v²−u²); ratio to T_A = v²/(v²−u²) = 1/(1−ε²), ε = u/v. T_C = 2L/√(v²−u²); ratio to T_A = 1/√(1−ε²); T_B/T_C = 1/√(1−ε²). ΔT = T_B − T_C = T_A(1/(1−ε²) − 1/√(1−ε²)) ≈ T_A·ε²/2 = (2L/v)(u²/2v²) = L u²/v³. Loss-vs-gain: 1/(v−u) − 1/v = u/(v(v−u)) > 1/v − 1/(v+u) = u/(v(v+u)). Convexity core: E[1/x] ≥ 1/E[x] for the paired speeds. Every round trip is slowed ⇒ single-trip blindness; differential probe is second order; historical echo: the null of the ether-wind timing experiment (Michelson–Morley, 1887) is the empirical half; the principle survives in relativity as frame invariance. All arithmetic symbolic and exact.
