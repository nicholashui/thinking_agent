# Test Case: m095-NEG-01

### Test Case ID: m095-NEG-01
- **Human Thinking Model**: Fast-and-Frugal Decision Trees (Gigerenzer)
- **Type**: Negative
- **Scenario**:
  One quarter later at Brightwater General. A new patient mix has arrived: atypical elderly presentations (diaphoresis and age ≥ 65, but no ST elevation and normal troponin on arrival). The unit runs the fast-and-frugal tree from the previous quarter's review — ST = 1 → admit; else TRP = 1 → admit; else monitor (C1-first order, and note either cue order admits the same union, so the tree's count is order-invariant). In week 1, the unit collected a 20-patient pilot (the first 20 of the table below) to re-check the cues: TRP scored 14/20 (70%), ST 13/20 (65%), SWT 13/20 (65%), AGE 10/20 (50%) — the top cues still look healthy, so the tree is kept as-is (a reorder is "within noise"; changing a validated checklist requires a study).

  The full 40-patient adjudicated cohort for the wave (same five cues; outcome = confirmed acute coronary event) is in the table below. The analytics team has ALSO just re-fitted the hospital risk model on these 40 cases, adding a SWT×AGE interaction term (the atypical-elderly pattern the variant produces): score S = 2·SWT + 2·AGE + 1·TRP − 0.5·ST + 0.5·PRI; admit if S ≥ 3.5. Their re-fitted model scores 34/40 on the same cohort. Your task, for tonight's shift and the next two weeks of the wave: which rule should the unit run? A 500-case validation study would take ~6 weeks; the wave is forecast to peak in 2.
- **Context / Constraints**:
  - Decision window is now: the admission rule for the current wave must be set today; a 6-week study cannot inform it.
  - The 40-row adjudicated cohort is the best current evidence; the pilot (first 20 rows) straddled the regime change.
  - Rules must be applied exactly as specified (tree: ST ∨ TRP → admit; model: S ≥ 3.5 with the interaction).
- **Expected High-Quality Behavior (informative failure first)**:
  - The style's core move executes: top cue re-checked on the pilot, tree kept (1).
  - Then the style fails decisively as designed: it treats the cohort's cue collapse as a sampling problem, demands the 6-week validation study as the gate ("you cannot re-learn a cue from 40 cases"), and refuses the re-fitted model as "six parameters on 40 cases — in-sample overfit theater," keeping the tree for the wave (2).
  - Correct decision: compute on the table — deployed tree 19/40 (47.5%) with 5 false negatives, 4 of which are exactly the atypical-elderly signature (SWT=1, AGE=1, ST=0, TRP=0) sent home; no single cue reaches 65% (best: SWT 26/40); re-fitted model 34/40 (85%) with 2 false positives — the signal is combinatorial (SWT×AGE), so no one-cue-at-a-time tree can reach it; adopt the re-fitted rule now, route any ST-elevation positive to observation as a cheap safety net, pre-commit a monitoring gate (re-audit at next 60 patients; re-fit or revert if FP rate > 30% or any signature FN), and run the 6-week study in parallel, not as a gate (3).
  - Meta-lesson: when the chosen cue's validity breaks, pure frugality has no in-window recovery — the complex evidence (the interaction) is required, and the tree's transparency does not substitute for evidence (4).
- **Success Criteria / Scoring Rubric** (total 15; pass ≥ 12):

  - (b) Decisive failure: tree kept for the wave and/or 6-week study demanded as a gate; re-fitted model refused as in-sample overfit (1.5 pts)
  - (c) Cohort arithmetic: tree 19/40 (5 FN, 4 × atypical signature); best single cue 26/40 (65%); re-fitted model 34/40 (2 FP) (1.5 pts)
  - (d) Correct decision: adopt the re-fitted rule now; ST-elevation positives to observation; monitoring gate pre-committed; validation study parallel, not a gate (4 pts)
  - (e) Mechanism named: cue-selection fragility — single-cue validity collapsed between pilot and cohort; the signal is combinatorial; complex evidence required (4 pts)
  - (f) Meta-lesson: no in-window recovery for a broken top cue under pure frugality; transparency ≠ evidence (1.5 pts)
