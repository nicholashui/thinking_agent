### Test Case ID: m070-NEG-01
- **Human Thinking Model**: Evidence-Weighted SWOT
- **Type**: Negative
- **Scenario**:
  Westbrook Grid Ops — regional electricity distributor (320k customers). 2:07 AM, dispatch board. SCADA confirms a winding-class fault on the Feeder 41 substation transformer (no fire, no load risk elsewhere). 12,000 residential customers and one hospital are down. The dispatch manager asks for a structured decision brief. Two live options:
  - A — Hot-swap: mobile transformer available from a sister utility, ETA 3h, connection ≈ 1.5h, total ≈ 4.5h, rental + mobilization ≈ $120k. Historic: 9 prior swaps company-wide, 8 successful; only 1 ever at this substation class (successful); class-specific reliability ≈ 85–90% (crew estimate, no formal study).
  - B — Repair in place: technicians on site in 45 min, repair 6–8h, parts guaranteed in-stock, cost ≈ $40k. Historic success for this fault class ≈ 80%; failure extends to ≈ 10h.
  Fixed facts: hospital backup-generator fuel ≈ 4h (documented). Regulatory rule: outage > 8h → mandatory public escalation + ≈ $150k fine + executive briefing. Crew/overtime ≈ $15k either way.
  The brief must be delivered in under an hour.
- **Context / Constraints**: Time-critical (2 AM decision, hospital fuel at 4h, regulator line at 8h); single dominant question — which path restores power fastest and within constraints; no time or mandate for new data collection.
- **Expected High-Quality Behavior**: The style's own output must fail visibly here: (1) the 2x2 grading produces all-moderate grades — every quadrant is C/B with genuinely unanchored confidence (class-specific swap evidence is n = 1; any B–D grade is defensible, so grading is subjective), and the table contains no verdict; (2) recognize that the checklist has substituted for analysis — nothing in the graded table decides the dispatch; (3) the decision-relevant quantity is not in any quadrant: expected restore time per option — EV(A) = 0.85·4.5h + 0.15·10h ≈ 5.3h vs EV(B) = 0.80·7h + 0.20·10h ≈ 7.6h, against the 8h regulator line (B's tail = 20% ≥ 8h) and the 4h hospital line (a constraint on both, not a differentiator); (4) verdict: A (hot-swap) with a parallel-start rule — begin repair crew now (45-min option, cheap, cancelable) and commit to A when the mobile unit arrives unless repair is > 60% complete; hospital protocols triggered at 4h regardless.
- **Success Criteria / Scoring Rubric**:
  1. Detects that the graded SWOT output contains no decision-relevant verdict (ritual identified as substituting for analysis) (1 pt)
  2. Identifies expected restore time as the governing quantity (1 pt)
  3. Computes EVs explicitly (A ≈ 5.3h, B ≈ 7.6h, tails, 8h/4h lines) (1.5 pts)
  4. Reaches a verdict with a decision rule (A with parallel-start/fallback, or equivalent) (1 pt)
  5. Names the meta-lesson: unanchored grading + checklist-instead-of-instrument failure (0.5 pt)
- **Notes**: Grader-only reference. Decisive feature: the case is engineered so the style's documented weakness (evidence grading is subjective — the n = 1 class-specific sample makes any B–D grade defensible) and its structural limit (a 2x2 cannot carry an expected-value decision) jointly produce a non-decision; the correct move is instrument-swap to time-to-restore EV. Pure-style performance = a polished graded table with no verdict; that IS the informative failure. Reference answer: EV(A) ≈ 5.3h < EV(B) ≈ 7.6h; B's failure tail crosses the 8h fine line; hospital line binds both → choose A, start parallel repair as a cancelable option, trigger hospital protocols at 4h.
