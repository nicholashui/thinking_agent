### Test Case ID: m015-POS-01
- **Human Thinking Model**: Emergence & Complexity Awareness (Systems & Causal family)
- **Type**: Positive
- **Scenario**:
  Production incident: a cache-backed 3-tier platform (nginx → checkout/app service → Postgres with a shared "products" cache) shows p99 latency spiking from ~120 ms to ~2.1 s for exactly ~38 s, every ~5 minutes, at all hours. No errors, no user complaints, no component over budget. The on-call lead must diagnose the cause and hand over a fix. The team's playbook requires a "diagnostic plan" document before any change can be made.
  Budget: 6 probing actions (each probe = one observation or experiment, ~2–3 min each; the plan document itself is free but does not consume budget).
  The environment answers each probe honestly. Available probes and their grader-held results:
  - P1 App CPU/GC telemetry in the spike window → CPU < 40%, max GC pause 48 ms.
  - P2 DB slow-query log during spikes → empty (0 slow queries).
  - P3 nginx access-log pattern during spikes → spikes begin exactly at :00 and :05 clock marks, last 38 s, traffic clustered on 4–5 hot product keys.
  - P4 Scheduled jobs → a batch job fires every 5 min at :00/:05; its first step invalidates the cache namespace "products".
  - P5 Experiment: suspend invalidation for one 10-min cycle → spike disappears; re-enable → spike returns.
  - P6 Upstream CDN hit-ratio → drops from 0.94 to 0.11 in the same 38 s window.
  Deliverable: cause identified (or explicit "needs more probes" state) + a fix recommendation. Success is measured at decision time, not post hoc.
- **Context / Constraints**: The grader holds the reference cause: **cache stampede** — the scheduled invalidation at :00/:05 empties the "products" cache, and the first wave of requests after invalidation thunders to the origin (an interaction between healthy components; no single component is broken). The reference fix: jittered TTLs + stale-while-revalidate on reads, and stagger the invalidation (drain, don't flush). The trap: the playbook demands a plan first, and all six probes exist — the plan-first path can still "succeed" as an artifact while leaving the true cause at step 5 of 6, unverified.
- **Expected High-Quality Behavior**: Explicitly classify the system: intermittent + clock-aligned + all components individually healthy = **emergent interaction**, not a broken part — so planning from first principles is inferior to probing. Run ≥2 cheap probes with visible narrowing (P1/P2 rule out component faults; P3 exposes the clock-aligned pattern; P4 correlates; P5 confirms causality by experiment), converge on the reference cause, and deliver the fix. Keep plan artifacts to one, after the probes. Total budget used ≤ 5 probes.
- **Success Criteria / Scoring Rubric** (max 5 pts, graded against the reference cause and the fixed probe table):
  1. Complexity classification explicit and correct: emergent interaction (not component failure), with the evidence that justifies probe-first over plan-first (1 pt; 0.5 if "maybe an interaction" is only mentioned).
  2. Probe-sense-respond loop: ≥2 probes executed, each with a stated narrowing effect on the hypothesis space (2 pts; 1 pt for probes without narrowing statements).
  3. Converges to the reference cause — scheduled-invalidation cache stampede (1 pt; 0.5 for ranking it first without the P5 experiment).
  4. Anti-over-planning: ≤1 plan artifact and it is produced after probes; a comprehensive plan delivered with 0 probes executed scores 0 on this item (1 pt).
- **Notes**: Grader-only reference solution: fully deterministic — the probe table is fixed, so probe-based and plan-based outcomes are directly comparable. The intended non-obvious twist: the "diagnostic plan" deliverable is a decoy; a correct plan exists and is reachable, but only if the agent recognizes that analysis value decays while probe value rises once the interaction signature (clock-aligned, healthy parts) is seen. Verifiable without subjective judgment: did the trace run probes (rubric 2), which cause it converged on (rubric 3), and how many plan artifacts came before probes (rubric 4)?
