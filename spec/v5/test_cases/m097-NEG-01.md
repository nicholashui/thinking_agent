### Test Case ID: m097-NEG-01
- **Human Thinking Model**: Reference Class Forecasting (Kahneman)
- **Type**: Negative
- **Scenario**:
  Kestrel Digital (30-person digital agency). Over 4 years they have delivered 14 catalog/e-commerce builds on their internal platform (Kestrel CMS). Nine are directly comparable — same internal platform, same 6-person product team, no external dependencies, fixed-price frozen specs: durations 5.0, 5.5, 6.0, 6.5, 5.0, 7.0, 6.0, 6.5, 5.5 weeks (median 6.0, mean 5.9, range 5–7). The engagement manager's inside plan for "Project Curlew" — a mid-market catalog site on Kestrel CMS, same team, spec frozen at kickoff, only the standard 3 integrations, no platform work: 6 weeks, $110K, team of 6.
  Bait: a widely circulated industry survey, "E-Commerce Platform Project Delivery" (n=412 projects across agencies and in-house teams): median duration 9 months, mean 10.5, sd 5, range 4–24; the survey notes most projects overrun and initial estimates average ~1.9× below actual. A delivery consultant (contractor, not on the team) cites the survey at kickoff: "Estimate error alone — you should plan on 3–4 months at minimum, probably 6+."
  Your task: produce the forecast and plan for Curlew — duration, budget, and how to respond to the consultant — with the reasoning.
- **Context / Constraints**: Spec frozen at kickoff; platform and team unchanged; client pays fixed price; deliverable is an internal forecast + plan; no external clock except the delivery date promised by the inside plan.
- **Expected High-Quality Behavior**: The style's own output must fail visibly here: (1) it executes its core move — refuses the inside view, finds the reference class ("e-commerce platform projects"), reads the industry distribution, and forecasts from it: plan ≈9–12 months (80% interval ≈4–17), budget ≈$400–600K, fixed price at risk → renegotiate — a ~6× overcorrection against the true class; (2) it fails on its registered weakness — reference class selection: it picks the industry-wide class over Kestrel's own 9-build history (same platform, same team, frozen specs, no novel integration), possibly rejecting the narrow class as "the inside view's echo chamber," and it applies the survey's 1.9× factor as if within-class quantities port across classes; (3) the correct behavior: the class-selection test — decide class membership by structural similarity (platform, team, spec status, integration novelty), which places Curlew in the narrow class; the narrow distribution (median 6.0, range 5–7) is itself the reference class; forecast 5–8 weeks, budget $110–135K with a modest buffer; the inside plan (6 weeks) is a consistency check that passes because it is anchored in the narrow class's own history; (4) the divergence rule: when the inside estimate is far outside a candidate class (6 weeks vs 9-month median — 6×), suspect the class before the estimate — divergence flags misclassification, not bias; (5) meta-lesson: the outside view is only as good as the class; class selection is the dominant risk of reference-class forecasting, and surface labels ("e-commerce project") are not classes.
- **Success Criteria / Scoring Rubric**:
  1. Executes the outside-view move: a reference class + distribution identified, forecast drawn from it, the inside plan doubted on class grounds (1 pt)
  2. Fails decisively (the informative failure): selects the industry class over the firm's own 9-build history and/or applies the 1.9× factor across classes, yielding a ~6× wrong forecast (~9–12 months / $400–600K vs 5–7 weeks) (1 pt)
  3. Correct behavior requires the class-selection test: structural membership decides the class; the narrow class's distribution is the forecast basis; the inside estimate is evidence about class membership, not noise (1.5 pts)
  4. Applies the divergence rule: the 6× gap flags misclassification, not bias — check the class before discarding the estimate (1 pt)
  5. Names the meta-lesson: class selection, not distribution reading, is where reference-class forecasting fails (0.5 pt)
- **Notes**: Grader-only reference. Decisive feature: two candidate classes with opposite distributions are both in plain view, and the deciding structural facts (same platform, same team, frozen spec, no novel integration) select the narrow class — the pure style is baited into the broad class by the surface label and the loud survey. Reference answer: narrow class is the reference class (n=9, median 6.0 weeks, range 5–7): forecast 5–8 weeks, budget $110–135K, hold the fixed price, and tell the consultant his survey's class is structurally different. "Plan on 3–4 months minimum" is the failure.
