### Test Case ID: m067-NEG-01
- **Human Thinking Model**: Thought Experiment (Gedankenexperiment) (Additional Expert Strategies; id m067)
- **Type**: Negative
- **Scenario**:
  A thought experiment about democracy. Idealized world: a large electorate of N citizens (N ≈ 10⁷), a two-candidate election, every citizen prefers one candidate over the other. Voting costs a citizen the value of an hour of time and effort, c > 0 (say ≈ $10). The benefit if your preferred candidate wins is b (say up to $1,000 of value to you). Your single vote changes the election outcome only in the event of an exact tie, which has probability p ≈ 1/N (for large N, order 10⁻⁷).
  Run this idealized scenario and extract its logical core: (1) What is the expected value of voting? (2) What does the idealized scenario conclude about the rationality of voting and about the sustainability of democracy? (3) State the strongest principle the scenario isolates.
- **Context / Constraints**: Symbolic and order-of-magnitude answers fine; the idealization is the model as given — citizens are expected-value maximizers, the only value of a vote is its chance of changing the outcome, no other motives exist, no social or expressive considerations, elections are exactly tied-or-not with no other margin effects. The problem explicitly invites you to draw the conclusion the idealized world forces. Numbers given for N, c, b are order-of-magnitude anchors.
- **Expected High-Quality Behavior**: This case is built so the pure thought-experiment style produces the wrong conclusion — its documented failure mode: idealization drift (the stripped model is treated as the real world) and no empirical check. The trap: a clean, rigorous derivation — EV(vote) = p·b − c ≈ 10⁻⁷·1000 − 10 < 0, every citizen reasons identically, turnout ≈ 0, hence "democracy is irrational and collapses" — presented as a conclusion about the real world. The correct analysis: (i) run the idealized core honestly (it is correct arithmetic); (ii) then perform the empirical check the style skips — measured turnout in established democracies is 50–90% (US presidential 2020 ≈ 66.8% of eligible; non-compulsory Denmark/Sweden ≈ 84%), falsifying the "turnout ≈ 0" prediction by roughly 60 percentage points; (iii) identify the drift: the idealization deleted expressive, duty, and social utilities that empirical work shows matter (e.g., field experiments where social-pressure mailers raise turnout ≈ 8 points); the failure is a misspecified utility function, not a discovery about the world; (iv) recover the intact logical core and repair: the scenario genuinely isolates the collective-action/free-rider structure of voting (public good, private cost) — the right principle is "instrumental value alone cannot sustain democratic participation; norms and expressive value bridge the gap," not "democracy is irrational"; (v) note that the idealized logic is correct at small N (a 20-person committee: p ≈ 0.05, p·b ≈ $50 > c).
- **Success Criteria / Scoring Rubric**:
  1. Idealized core derived honestly: p ≈ 1/N, EV(vote) = p·b − c < 0 by ~5 orders of magnitude → abstain; everyone reasons so → turnout ≈ 0 (1 pt)
  2. Empirical check performed: measured turnout 50–90% (specific citations: US 2020 ≈ 66.8%, Nordic ≈ 84%) and the falsification quantified (~60 points vs the predicted ≈ 0) (1 pt)
  3. Drift identified precisely: instrumental-only utility function; deleted expressive/duty/social terms are empirically real (social-pressure experiment evidence) (1 pt)
  4. Principle recovered in repaired form: free-rider/collective-action core is retained; the conclusion becomes "norms/expressive value sustain participation," NOT "democracy is irrational"; small-N validity (committee) noted (1 pt)
  5. Does NOT present "nobody rationally votes / democracy is irrational" as the final answer (1 pt)
  6. Style-aware closing: states where the idealization helped (isolating the collective-action core) and where it failed (no empirical check) (0.5 pt)
- **Notes**: Grader-only reference. EV(vote) = p·b − c; with p ≈ 10⁻⁷, b = $1,000: p·b = $10⁻⁴ ≈ $0.0001, vs c ≈ $10 — negative by ~5 orders of magnitude. Turnout evidence (public base rates): US presidential 2020 ≈ 66.8% of eligible voters, 2016 ≈ 60.1%; Denmark 2022 ≈ 84%, Sweden 2022 ≈ 84% (no compulsory voting). Gerber–Green field experiments: social-pressure mailers ("your neighbors will know") raise turnout by ~8 points — direct evidence of non-instrumental utility. The judgment is structural, not arithmetical: the pure style's derivation is valid inside its own stripped world; the failure is treating the stripped world as the real one. Small-N sanity check: N = 20, p ≈ 1/√(2π·5) per two candidates... order 0.05 → p·b ≈ $50 > c ≈ $10 — the logic flips at small N, confirming the repair.
