### Test Case ID: m007-POS-01
- **Human Thinking Model**: Expected Value Thinking (Probabilistic & Bayesian family)
- **Type**: Positive
- **Scenario**:
  A manufacturer has won a one-year contract for a custom component with random annual demand D. Demand states: Low (D = 100k units, probability 0.50), Medium (D = 200k, probability 0.25), High (D = 300k, probability 0.25). Every unit produced in-house earns a $3.00 margin; units demanded beyond in-house capacity must be subcontracted, which nets only $0.80 per unit (subcontractor charges $2.20 against the $3.00 revenue). Before demand is known, the firm must choose exactly one option:
  - Machine A: capacity 150k units/year, purchase cost $50k.
  - Machine B: capacity 300k units/year, purchase cost $120k.
  - Decline the contract: $0.
  One-year horizon, no salvage value, risk-neutral firm.
  Question: Which option maximizes expected profit? Show the state-by-state table and the full EV arithmetic for every option.
- **Context / Constraints**: All probabilities and payoffs fully specified. Risk-neutral. One decision, one year; no staging, expansion, insurance, or negotiation. Subcontracting is the only flexibility and its price is fixed.
- **Expected High-Quality Behavior**: Enumerate all three options; per option, compute state-by-state profit (in-house margin capped at capacity, subcontract margin on overflow); weight by probabilities; sum to EVs; select the maximum; run sensitivity on the subcontract margin (breakeven) and on the demand probabilities (robustness of the choice).
- **Success Criteria / Scoring Rubric**:
  1. EV(A) = $365k computed correctly (1 pt)
  2. EV(B) = $405k computed correctly (1 pt)
  3. EV(C) = $0 (0.5 pt)
  4. Correct decision: Machine B, $40k ahead of A (1 pt)
  5. State-by-state table correct, incl. overflow/subcontract arithmetic ($3.00 in-house vs $0.80 net on overflow) (1 pt)
  6. Breakeven subcontract net margin m* = $1.60/unit for A to tie B (1 pt)
  7. Probability robustness: B beats A whenever P(High) > 3/44 ≈ 0.068; decision robust at P(High) = 0.25 (0.5 pt)
- **Notes**: Grader-only reference. EV(A) = −50 + 0.5(300) + 0.25(490) + 0.25(570) = 365; EV(B) = −120 + 0.5(300) + 0.25(600) + 0.25(900) = 405; EV(C) = 0. As a function of net subcontract margin m: EV(A) = 325 + 50m → ties B at m* = 1.60 (i.e., subcontract cost < $1.40 flips the choice). As a function of P(High) = h (P(Med) = 0.5 − h): EV(A) = 345 + 80h, EV(B) = 330 + 300h → A wins only if h < 3/44 ≈ 0.068. Independent verification path: EV(B) = 3·E[D] − 120, E[D] = 175k → 525 − 120 = 405. All values exact integers (in $k) or simple fractions; no subjective judgment required; fully verifiable by recomputation.
