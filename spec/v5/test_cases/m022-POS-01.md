### Test Case ID: m022-POS-01
- **Human Thinking Model**: Decision Trees & Scenario Planning (decision nodes, chance nodes, branch values, rollback, sensitivity, contingent policy)
- **Type**: Positive
- **Scenario**: Aurigen Biotech, a 40-person company with $120M cash, must decide today whether to continue Phase 3 development of candidate AT-9 or license it now to a large pharma. Continuing Phase 3: trial cost $40M over 12 months; calibrated trial-success probability 0.6 (Phase 2 signal + comparable-trial base rate), failure 0.4. If the trial succeeds, Aurigen faces a second decision: launch alone or accept the $150M upfront licensing offer on the table. Launching alone costs $80M (sales force + manufacturing scale); market outcome is then High demand (p=0.5, gross value $400M) or Low demand (p=0.5, gross value $100M). If the trial fails, Aurigen faces a third decision: abandon (value $0) or run a targeted rescue study costing $15M with fix probability 0.25 (comparable rescue-program base rate); a fixed trial reaches the same post-success state. The alternative to continuing today is a pre-Phase-3 license for $55M upfront.
- **Context / Constraints**: All probabilities are deliberately checkable and calibrated: 0.6 trial success, 0.5/0.5 market, 0.25 rescue. The rescue option (cost $15M, p=0.25) is present in the scenario data but NOT flagged as a decision option — a sloppy analysis treats trial failure as automatic abandonment and never costs it. Cash is not a binding constraint ($40M trial and $80M launch fit in the $120M war chest). The $150M and $55M offers are firm.
- **Expected High-Quality Behavior**: (1) Draw the full tree: 3 decision nodes (today / post-success / post-failure) and 3 chance nodes (trial, market, rescue) with branch values. (2) Roll back: success node = max(launch 170, license 150) = 170; failure node = max(rescue 27.5, abandon 0) = 27.5; root = 0.6×170 + 0.4×27.5 − 40 = 73 > 55 → continue. (3) State the optimal policy as a contingent rule, not a number: "Run Phase 3; on success launch alone (reject the $150M license); on failure run the $15M rescue (do not abandon); reject the $55M pre-trial license." (4) Run sensitivity: trial-success break-even vs the $55M outside option is p* = 0.474 (with the rescue arm; 0.56 without it); the success-node license would need to exceed $170M to switch the launch decision; the rescue fix-probability break-even is q* = 0.088. (5) Declare in-frame what the tree cannot hold (portfolio correlation, financing dilution, regulatory tail) without derailing the decision.
- **Success Criteria / Scoring Rubric**:
  - [ ] All three decision nodes and three chance nodes visible with branch values
  - [ ] Fold-back values present and correct: 170 (success node), 27.5 (failure node), 73 (root), threshold ≈ 0.474
  - [ ] Rescue option costed at the failure node (failure branch NOT stubbed as abandon)
  - [ ] Optimal policy stated as a contingent rule (continue; launch-on-success; rescue-on-failure; reject both license offers as framed)
  - [ ] ≥1 sensitivity result computed (p* threshold and/or the $170M license threshold)
  - [ ] Verdict: continue Phase 3; an answer that stubs the failure branch as abandonment (root EV 62, p* 0.56) should score below on Depth even if the conclusion agrees
- **Notes**: The case is gradeable by arithmetic: every fold-back number is checkable, and the failure-branch stub (62 vs 73; 0.56 vs 0.474) is a quantifiable gap. The buried rescue option is what separates a full tree from a success-path-only analysis — the tree's power is that its structure FORCES the failure branch to be completed.
