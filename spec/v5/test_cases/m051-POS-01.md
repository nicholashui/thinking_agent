### Test Case ID: m051-POS-01
- **Human Thinking Model**: Expected Value in Startup Portfolios (VC) (Domain-Specialized; family: Probabilistic & Bayesian)
- **Type**: Positive
- **Scenario**:
  Halcyon Ventures manages a $100M fund with a 3x target ($300M expected return). The GP must choose one deployment strategy before any capital is committed:
  - Strategy A "spray-and-hold": 50 checks of $2M, no follow-ons. Per-check outcome distribution (multiple of the $2M check): 60% fail → 0x ($0); 25% → 1x ($2M); 10% → 5x ($10M); 4% → 15x ($30M); 1% → 50x ($100M). Outcomes independent across companies.
  - Strategy B "spray + follow-on": 25 checks of $2M ($50M), reserving $50M for follow-ons. Every company in the 5x/15x/50x classes (combined probability 15% per check) receives a $2M follow-on check and is then worth the class multiple on the full $4M (e.g., a 5x company returns 5 x $4M = $20M); 0x and 1x companies get no follow-on. Follow-on reserve not deployed is returned at 1x (par).
  Fund multiple = total expected return / $100M; capital not deployed returns at par.
  Question: Which strategy maximizes expected fund return? Compute portfolio EVs and multiples for both; state what it would take to reach the 3x target; identify the parameter that dominates the answer.
- **Context / Constraints**: All probabilities and multiples fully specified; outcomes independent; risk-neutral fund; no other instruments (no secondary sales, dilution, carry, or fees); follow-on rule fixed (only 5x/15x/50x classes qualify); unused capital returned at par. Horizon = fund life; no discounting.
- **Expected High-Quality Behavior**: Compute the per-check EV from the power-law distribution; scale to portfolio EV(A) by linearity; compute EV(B) with the follow-on uplift and idle-capital return; select the higher; run sensitivity on (i) follow-on effectiveness f (multiple earned on follow-on capital) with breakeven, (ii) the 50x tail hit rate and its share of total EV, (iii) the 3x target gap. The counterfactual "same $100M in 25 checks of $4M" must be checked so undifferentiated check size is not confused with follow-on concentration.
- **Success Criteria / Scoring Rubric**:
  1. Per-check EV = $3.7M (1.85x) from 0.25x2 + 0.10x10 + 0.04x30 + 0.01x100 (1 pt)
  2. EV(A) = 50 x 3.7 = $185M → 1.85x fund multiple (1 pt)
  3. EV(B): per-company EV = 0.25x2 + 0.10x20 + 0.04x60 + 0.01x200 = $6.9M; portfolio = 25 x 6.9 = $172.5M + idle $42.5M = $215M → 2.15x (1 pt)
  4. Correct decision: Strategy B, ahead of A by $30M (1 pt)
  5. Follow-on effectiveness breakeven f* = 0.625 (B ties A if follow-on capital earns only 62.5% of the class multiple) (1 pt)
  6. Tail dominance: 50x bucket = 27% of EV(A), 29% of EV(B); tail hit rate required for the 3x target p* = 2.7% vs the modeled 1% — honest target gap (1 pt)
  7. Counterfactual: 25 checks of $4M (no follow-ons) = $185M = A — larger undifferentiated checks add nothing; only follow-on concentration does (0.5 pt)
- **Notes**: Grader-only reference. EV(A) = 50 x 3.7 = 185; per-check 3.7 = 0.5 + 1.0 + 1.2 + 1.0. EV(B): base 3.7 + follow-on uplift 3.2 (= 0.10x10 + 0.04x30 + 0.01x100) = 6.9; 25 x 6.9 = 172.5; expected follow-ons = 25 x 0.15 = 3.75 (deploy $7.5M); idle = 50 − 7.5 = 42.5; 172.5 + 42.5 = 215. B(f) = 25(3.7 + 3.2f) + 42.5 = 135 + 80f; f* = 50/80 = 0.625. B(p) = 165 + 5000p; 3x target → p* = 135/5000 = 0.027. 50x share: 1.0/3.7 = 27.0%; 2.0/6.9 = 29.0%. Independent verification path: EV(A) = 50 x E[check] and EV(25 x $4M) = 25 x 2 x 3.7 = 185. All arithmetic exact; no subjective inputs.
