### Test Case ID: m065-POS-01
- **Human Thinking Model**: Margin of Safety in Engineering Design
- **Type**: Positive
- **Scenario**:
  SkyLift — a tethered facade-inspection platform (22 kg aircraft on a 40 m tether). Your task: select the tether line core (the load-bearing member inside the cable, with power/data bundled around it). The tether carries the aircraft's full weight through the flight envelope; failure = aircraft drop over a pedestrian plaza.
  Given engineering data:
  - Static design load at full reel-out: 280 N (22 kg aircraft + line self-weight).
  - Field telemetry, 2,100 flights: 95th-percentile peak dynamic load = 2.2× static (reel transients + gusts), 99th = 3.1×, worst-case 3σ gust + reel-stall transient = 3.7× static → 1,036 N.
  - Model error: tether FEA vs strain-gauge field measurements, documented test/model ratio 0.87 for this line class.
  - Cable options (single continuous core): **A** — 4 mm, datasheet nominal breaking strength 1,600 N, certified minimum (AQL) 1,440 N, 36 g/m; **B** — 5 mm, nominal 2,400 N, certified minimum 2,160 N, 54 g/m; **C** — 6 mm, nominal 3,200 N, 80 g/m.
  - Knockdown factors (lab + field data): termination splice efficiency 0.92; UV/humidity environmental −8%; end-of-certified-life (500 h) abrasion wear −12%.
  - Reel/winch budget: tether must fit the reel carriage, cap 60 g/m at 40 m reel-out (C does not fit; B fits at 54 g/m).
  - Design requirement (the graded event): the line must survive the 3σ gust event **at end of certified service life** (3 successful static proof tests), and must show no plastic set at the 99th-percentile event mid-life. Factor-of-safety-in-spirit: target Margin of Safety ≥ +0.10.
  A junior engineer's draft: "FS 5 on static: 5 × 280 = 1,400 N ≤ 1,600 N nominal → cable A passes; margin 1.54× on the 3σ peak — plenty." Your deliverable: the cable selection with the full margin computation, the graded-event check, and a sensitivity ranking of the factors.
- **Context / Constraints**: Weight matters (B adds 0.72 kg ≈ 3% of AUW — real but acceptable); C is off the table (reel cap). All factors above are measured, not assumed. The requirement is explicit: survive end-of-life 3σ event; no plastic set at 99th-pct mid-life.
- **Expected High-Quality Behavior**: (1) load-side stack: design load = 3σ peak × model-error factor = 1,036 × 1.15 ≈ 1,191 N (not static × FS table); (2) strength-side stack: allowable = certified minimum (not datasheet nominal) × termination × environmental × wear = 2,160 × 0.92 × 0.92 × 0.88 ≈ 1,609 N for B, 1,440 × 0.745 ≈ 1,073 N for A; (3) MS = allowable/design load − 1: A = −0.10 → FAILS the event, B = +0.35 → PASSES; (4) explicitly reject the junior draft's FS-to-static + nominal-strength move, naming the failure it masks (design load 1,191 N > A's residual 1,073 N); (5) sensitivity ranking: wear and the 3σ load factor dominate — set inspection/replacement cadence accordingly; (6) frame the acceptance criterion as a testable event (proof test at 1,191 N on end-of-life samples + 998 N mid-life no-set check).
- **Success Criteria / Scoring Rubric**:
  1. Load stack computed explicitly: 1,036 × 1.15 = 1,191 N (1 pt)
  2. Strength stack computed explicitly from certified min × 0.92 × 0.92 × 0.88 (product 0.745) (1 pt)
  3. MS per option: A −0.10 (fail), B +0.35 (pass) — correct selection (1 pt)
  4. Junior draft's FS-5/nominal-strength error named and rejected with the math (1 pt)
  5. Sensitivity ranking with the dominant factors (wear, load factor) + control cadence (1 pt)
  6. Acceptance framed as graded event (end-of-life proof test; mid-life no-set) (0.5 pt)
  7. Weight consequence of B accepted within the reel cap; C blocked by constraint (0.5 pt)
- **Notes**: Grader-only reference. Decisive feature: the case is engineered so derating is the whole answer — the event load (1,191 N) sits between A's derated residual (1,073 N, fails) and B's (1,609 N, passes), so every shortcut (nominal strength, FS-on-static, ignoring wear) selects the cable that fails the graded event. MS values: A = 1,073/1,191 − 1 = −0.10; B = 1,609/1,191 − 1 = +0.35. Mid-life residuals: A 1,219 N, B 1,828 N, both > 998 N (99th-pct with model error) — no plastic set ✓. The three uncertainty sources the model names — model error (0.87 ratio), material variance (certified min vs nominal), load uncertainty (3σ gust) — are all in the stack.
