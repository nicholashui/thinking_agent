# Test Case: m047-POS-01

### Test Case ID: m047-POS-01
- **Human Thinking Model**: Bayesian Updating in Medical Diagnosis (domain-specialized, probabilistic & Bayesian family)
- **Type**: Positive
- **Scenario**:
  A 52-year-old woman's routine screening mammogram shows suspicious microcalcifications (positive). The screening registry for this population reports a measured cancer prevalence of 0.5% (5 per 1000 screened). Three tests are available, all with exact, validated operating characteristics:
  - Mammogram (the screen): Se = 0.87, Sp = 0.89
  - Ultrasound: Se = 0.82, Sp = 0.94
  - MRI: Se = 0.94, Sp = 0.81
  The team must decide the follow-up. The radiologist argues MRI is obviously the best next test ("highest sensitivity"). A colleague argues for ultrasound ("cheaper, and it's what we normally do"). The patient asks what the numbers mean.
  Questions:
  1. After the positive mammogram, what is P(cancer | M+)?
  2. Which test should be ordered next? Rank the available tests by information value and state the ranking criterion.
  3. After the recommended next test comes back positive, what is P(cancer | M+, U+)?
  4. Does the order in which the tests are administered change the final posterior?
- **Context / Constraints**: All inputs exact and given; posteriors exactly computable and checkable (answers: 87/2276 ≈ 3.8%; ultrasound is next-best with LR+ = 41/3 ≈ 13.7 > MRI's 94/19 ≈ 4.9; final 3567/10134 ≈ 35.2%). Conditional independence of the three tests given cancer status is a stated property the reasoner must declare and justify. Population prior (0.5%) is a registry measurement, not a guess.
- **Expected High-Quality Behavior**: State the prior, the LR+ of every test, and the independence assumption explicitly; compute the posterior after the screen (3.8%); rank tests by positive information value (LR+), not sensitivity — the highest-sensitivity test (MRI 0.94) has the lowest LR+ (4.9); compute the sequential posterior after the next-best test (35.2%); demonstrate order-invariance by recomputing the reversed path; run a prior-sensitivity pass; and interpret clinically — including the negative branch (a normal ultrasound after a positive mammogram drops the posterior to ≈ 0.8%, back near the screening baseline).
- **Success Criteria / Scoring Rubric** (total 15; pass ≥ 12):
  - (a) P(cancer | M+) = 87/2276 ≈ 0.038 (3 pts)
  - (b) Next-test ranking by LR+ with the criterion stated: ultrasound (41/3 ≈ 13.7) > repeat mammogram (87/11 ≈ 7.9) > MRI (94/19 ≈ 4.9); explicit note that higher sensitivity ≠ higher information (4 pts)
  - (c) P(cancer | M+, U+) = 3567/10134 ≈ 0.352 via sequential updating with the prior carried forward (5 pts)
  - (d) At least one non-obvious insight: order-invariance (reversed path recomputed to the same posterior), the negative-US branch (LR− = 9/47 → posterior ≈ 0.76%), or a formal prior-sensitivity pass (prior 1% → ≈ 7.4%; prior 0.1% → ≈ 0.79%) (3 pts)
- **Notes**: Verifiability gate: every numeric claim checkable by hand; any solution whose numbers do not match 87/2276, 13.7 vs 4.9, and 3567/10134 fails regardless of prose quality. The clinical framing is decorative; the posterior mathematics and the information-value ordering are the object under test.
